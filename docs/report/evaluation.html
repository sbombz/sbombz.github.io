Evaluation

Evaluation

I think my project meets all of the requirements as I have described it in the Meeting the Brief section and the video. Overall, I am proud of my project and learnt a lot. The things I struggled most with were the modelling code and the use of MatPlotLib.

For the planning I originally did not have a complete Idea in my head which slowed down development, but once I finalised the plan I was able to stay on task and consistently hit my goals and I believe that I implemented most of the things I had planned. This is an area that I wish to improve in the future, and believe that this project helped me to understand how valuable planning can be.

Improvements

Improvement Description Justification
Wireless Communication I would like my artefact to work via Bluetooth or radio rather than over serial. Long-distance communication would be more useful for monitoring outdoors. This would make the system more practical in real-world environments where devices are not directly connected.
More Accurate Sensors Buy higher-quality sensors to improve data reliability. The current sensors were unpredictable and values fluctuated randomly, making it harder to interpret data. More accurate sensors would improve the quality of the model.
Improve Algorithm Accuracy Increase the mathematical accuracy of the fire risk algorithm. Currently, all factors affect fire risk equally, but in reality some factors (like soil moisture) have a greater impact. Improving this would make the model more realistic.
