Introduction

For my 2026 LC project, I decided to create forest monitoring software which detects when a tree is at risk of a fire. To do this I used a Microbit, a smart greenhouse kit and a python backend. This idea was very interesting and important to me, as this combines my passion for the environment and Computer Science.
All images in this project can be enlarged simply by clicking on them if they are too small to read

Meeting the Brief

Basic Requirements
Requirement Meets Requirement?
BR1 Yes - I have built an embedded system (microbit greenhouse) that once turned on reads data from different sensors automatically: Digital Input: Flame Sensor (returns 0 or 1) Analog Input: Soil Moisture Sensor Primary Output: Returns the probability of a fire occurring in Thonny based on sensor data, using this value a light is activated on the microbit if fire risk exceeds 50%
BR2 Collect: Data from the Flame, Light, Soil Humidity, CO2 and Air Humidity sensors is sent over Serial to Thonny where it is processed Store: The values from the sensors are stored in a .csv file with a timestamp on the PC
BR3 Yes-As shown in the video, the embedded system responds to a decreased moisture level, we can see an increase in fire risk on the backend and subsequently the water pump and LED screen turn on. I was unable to show the fire sensor in action as I did not have permission to use matches or a lighter to activate it.










Advanced Requirements
Requirement Meets Requirement?
AR1 Yes-The file “firesim.py” uses a graphical representation of a forest fire using matplotlib. The tree density and fire chance can be configured to better model a variety of climates and biomes and it takes the data from the sensor's mean and standard deviation to model the forest fire more accurately. After the code is run some statistics are displayed about the simulation that was run.
AR2 Yes- I have created two additional .csv files for each What-If scenario. These .csv files can be ran through my simulation or simply scanned using the normal firerisk calculation to see the increase. You can view the results for these in the video
My What-If Scenarios
What will happen if a forest fire happens after temperature has increased due to an external factor, e.g global warming?
What will happen if a fire occurs in forests with less rainfall or harsher light intensity
AR3 Yes - I have created a feedback mechanism so that if fire risk exceeds a certain percentage (currently set to 50%) An alert will be sent, turning on the red LED display on the microbit connected to the system. The water pump connected to my greenhouse will also turn on to increase soil moisture, mitigating fire risk.. If the fire sensor detects a flame the pump will also turn on to extinguish it as soon as possible. Once the risk drops back below 50% the pump and led screen return to normal
